# M7-Sustentavel
# Aplicativo que faz oito perguntas de sim ou não para você, onde a cada resposta ele te fala se você está sendo sustentável ou não;
# Se a resposta for 'sim' para hábitos não sustentáveis, ele te dá uma dica de como você pode alterar/melhorar esses hábitos;
# Serve para concientizar a pessoa sobre os hábitos diários dela e como eles afetam o meio ambiente.
